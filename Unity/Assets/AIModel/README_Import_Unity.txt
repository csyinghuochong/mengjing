Stone Magic Circle - Unity 2022 URP

1. Drag StoneMagicCircle.obj and StoneMagicCircle.mtl into Assets.
2. Place StoneMagicCircle.obj into your scene; position Y slightly above the sand ground.
3. Scale: 1 Unity unit = 1 meter; approximate diameter 8.5m.
4. If materials do not auto-import, create 2 URP/Lit materials and assign colors:
   Stone_Slabs #8B816F, Stone_Engravings #BCB197.
5. Stone-only geometry: no dirt/sand mesh. Existing terrain shows through gaps.
6. Optional GLB provided for glTF import packages (e.g. glTFast).
7. All stones are separate connected components inside the mesh, but grouped in 2 material objects.
