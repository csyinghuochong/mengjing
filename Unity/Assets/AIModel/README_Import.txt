Campsite Tent - Unity 2022 URP

Preferred: Drag Campsite_Tent.glb into Unity using glTFast package (Package Manager). This preserves material colors.
Alternative: import Campsite_Tent.obj (geometry only; create URP/Lit materials manually).
Size approximately 7.5 x 4.4 x 6 meters. Y is up. No terrain or soil mesh.
Model includes tent, awning, support poles, ropes, crates, barrels, table, banner, torch.
Low-poly prototype asset; not exact image reconstruction.
